# Actuation Controller Firmware

Motor controller firmware for SnackBot, running on a **Nucleo-F446RE**. It drives
two 30:1 37D gearmotors (64 CPR encoders) through a **Pololu 1213 dual MC33926**
driver and takes its orders from the Raspberry Pi over UART.

## What it does

- **Pi link** on UART4 (`A0` = TX, `A1` = RX, 9600 baud, `\n`-terminated CSV lines):
  - `motor-instruction`: `straight`, `reverse`, `stop`, `turn,<deg>`
  - `odometer-reset`, `leds-on-off`, `button-led-on-off`
  - The robot replies with `odometer`, `turn-complete` and `button-press`.
- **Speed control:** one PID per wheel at 50 Hz, with a setpoint ramp and anti-windup.
- **Turns** in place, ended and measured by the MPU-6050 gyro (encoders if no IMU), slowing near the end.
- **Safety:** stops if the Pi sends no motor instruction for 500 ms while driving.
- **Debug and tuning** over the ST-LINK USB port (115200): a status log, and the
  live `get` / `set` / `telem` commands used by `tools/pid_tune.py`.

All tunables (speeds, PID gains, geometry, timing) are in
[`Core/Inc/robot_config.h`](Core/Inc/robot_config.h).

## Build and flash

You need the **STM32Cube for VS Code** extension (it brings the Arm GCC toolchain,
CMake and Ninja).

1. Open this folder in VS Code.
2. **Build**, then **Run and Debug** to flash over the Nucleo's ST-LINK.

From a terminal, with `arm-none-eabi-gcc`, CMake and Ninja on your `PATH`:

```bash
cmake --preset Debug
cmake --build build/Debug
```

The output is `build/Debug/f446_blinky.elf`.

## Tuning the PID

```bash
pip3 install pyserial matplotlib
python3 tools/pid_tune.py            # or --demo to try it without hardware
```

It plots each wheel's setpoint, speed and duty live and lets you change the
gains. Copy the values you settle on into `robot_config.h`.

## Layout

| Path | Contents |
|---|---|
| `Core/Src/robot_app.c` | Main loop: Pi messages, watchdog, odometer reports, button, LED |
| `Core/Src/drive.c` | Per-wheel speed PID, odometry, turns |
| `Core/Src/pi_link.c` | Interrupt-driven UART4 (Pi) and USART2 (USB) line I/O |
| `Core/Src/motor.c`, `encoder.c` | MC33926 PWM / fault pins, quadrature encoders |
| `Core/Src/motor_demo.c` | Bench bring-up demo (`ROBOT_MODE 1` in `robot_config.h`) |
| `Drivers/` | ST HAL and CMSIS (generated by STM32CubeMX) |
| `f446_blinky.ioc` | STM32CubeMX project |
